okn-connection-map

Find out where the Proto-OKN knowledge graphs connect. Computed from the data, with evidence, and served to AI agents.

This is the live demo from the run of 15 October 2026. It uses the sample results already in this repository. Nothing here needs a login, and nothing here changes any OKN service.

The federation-wide findings. What the catalog reproduces, and what it misses.

Open report.html

2. Explorer

Pick one graph and see everything it reaches.

Open explorer.html

3. Join paths

Pick any two graphs. See what MCP-OKN answers today, beside what the data support, with evidence.

Open join_paths_demo.html

Try it yourself

git clone https://github.com/frink-okn/okn-connection-map.git
pip install -e .
ocm use-sample
ocm paths geoconnex ruralkg

Full instructions are in the README on GitHub. The MCP server is ocm mcp, with tools find_join_paths, connections_of, and list_graphs.

Run: 15 October 2026. Catalog used for that run: 26 September 2026. Follow-up against the catalog of 9 November 2026: maintainers have since added 10 of the 40 connections, 8 at exactly the count this tool computed. 30 are still missing, 13 still refused.
